## Codebase Patterns
- pandas 3.0.6 and pytest 9.1.1 are installed globally; no venv/requirements.txt in this repo, just call `python`/`python -m pytest -q` directly.
- pipeline.py functions are split into small, testable pieces (load_vendas, load_lojas, build_vendas_lojas, main) so tests/future stories can import and reuse them without re-running the whole pipeline from scratch.
- tests/test_pipeline.py uses a module-scoped autouse fixture that runs `python pipeline.py` once via subprocess, then each test reads the generated CSV(s) fresh. Follow this pattern for US-002/US-003 tests instead of re-invoking the pipeline per test.
- receita_brl must be read/cast as float64 explicitly (`.astype({"receita_brl": "float64"})`) - pandas 3.x can otherwise leave ambiguous dtypes.
- id_loja is cast to int64 on both CSVs before merging so the inner join matches correctly.
- Generated deliverables (vendas_lojas.csv, and later pivot_receita.csv, index.html) are committed to the repo root, not gitignored - they are PRD-required deliverables, not build artifacts.
